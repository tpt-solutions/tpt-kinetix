# TPT Kinetix documentation

Start with the [project README](../README.md) for what Kinetix is and how to
install it. The pages here go further.

## Using the CLI

- [User guide](user-guide.md): `remux`, `package`, `serve` and `live`, with the flags for encryption, limits and recording.
- [What works with my files](what-works-with-my-files.md): which containers and codecs each command takes
  (H.264 and AAC are copied, never decoded).
- [Migrating from ffmpeg / ffprobe](migrating-from-ffmpeg.md): which command
  does what, and what does not exist yet.
- `tpt-kinetix <command> --help` lists every flag, with examples for `probe`,
  `remux` and `package`.

## Status

- [Player and browser compatibility](compatibility.md): what each client was checked against, and what was not.
