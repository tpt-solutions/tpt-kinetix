# Code of conduct

TPT Kinetix follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Please read it before taking part in issues, pull requests or discussions.

Report unacceptable behaviour privately to the maintainers, through the
repository's GitHub profile or the private vulnerability reporting form
described in [SECURITY.md](SECURITY.md). Maintainers will review each report
and respond as the Covenant describes.
